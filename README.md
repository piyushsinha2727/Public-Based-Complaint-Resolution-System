# Public-Based Complaint Resolution System (PBCRS) 🏛️

An AI-assisted civic engagement platform designed to bridge the gap between citizens and local authorities for efficient grievance redressal.

## 🚀 Overview
PBCRS allows citizens to report public issues (such as potholes, waste management, or broken streetlights) with real-time location data and photo evidence. The system automates the workflow between citizens, administrators, and resolvers to ensure accountability and transparency.

## ✨ Key Features
* **Tri-Role Ecosystem:** Separate dashboards for **Citizens** (reporting), **Administrators** (oversight), and **Resolvers** (field workers).
* **AI-Powered Categorization:** Automatically identifies the type of issue from user descriptions/images.
* **Priority Scoring:** Uses an algorithm to rank complaints based on severity and public impact.
* **Real-time Tracking:** Citizens can monitor the status of their complaints from 'Pending' to 'Resolved'.
* **Evidence Verification:** Resolvers must upload proof of work to close a ticket.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Deployment:** Vercel

## 📂 Project Structure
* `index.html` - Landing page
* `login.html` / `signup.html` - Authentication
* `admin.html` - Administrative oversight panel
* `resolve.html` - Resolver/Worker interface for task management
* `home.html` - Citizen dashboard
